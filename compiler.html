Anatomy of his compiler

He wrote the compiler too — lexer, parser, optimiser and code generator, roughly 19,000 lines — so TempleOS never touches GCC. Here is what one line of HolyC meets on its way to machine code, stage by stage, in his own functions.

Each excerpt is the first function of its stage file, exactly as it appears in the tree. The notes describe the stage, not the man.

The pipeline

HolyC has no build system and no object files: #include a file at the command line and the JIT compiles it straight into memory. Read the full sources in the Compiler directory.
